## What to expect

This is the session that overruns. Not because the material is hard, but because you are simultaneously teaching 60 people to install a toolchain, create a GitHub repository, and type in a terminal. Budget **60–90 minutes** for tooling and plan the content around it. If you finish the day with everyone's tools working and pods formed, the session was a success.

Two things students consistently enjoy: the hand-count survey (they discover they are not the only one who has never written SQL) and SQL Island. Protect the 30 minutes for the game — it buys you more SQL intuition than any explanation you could give.

## Before class (15 minutes)

- [ ] Open [Module 1](../modules/01-introduction-and-local-first.md) in a browser **and** the slides in a second window — you will switch between them.
- [ ] Confirm the [portfolio template](https://github.com/iotempire/iot-portfolio-template) is reachable and that "Use this template" works from your account.
- [ ] Have the LMS announcement ready: the repo link, and one sentence on what to bring (a laptop and a GitHub account).
- [ ] Check the three failure modes in the room: no `gh`, no `sqlite3` on Windows, a corporate proxy on the wifi.

## Opening (20–25 minutes) — in this order

1. **whoami, 3 minutes, maximum.** Name, what you actually do, why databases. Students do not need your CV; they need to know you are a person who will answer questions. The slides have two `whoami` slides — use one.
2. **"Who are U?" — the hand-count, 7 minutes.** Read the questions from the module aloud and have them **write the answers down**, because this is the first entry of their portfolio: programming experience, SQL, databases, Python, terminal, Git, web apps, servers. Count hands out loud; the room needs to see it is normal to be new.
3. **"This is an experiment", 5 minutes.** Modern education principles, you in the centre, meaningful content, no sieve. Be explicit that assessment is not an exam — and point at the syllabus rather than paraphrasing it.
4. **Open the workbook on screen, 5 minutes.** Show the module index, then the syllabus. Say the sentence that saves the term: *"Everything I ask you to do is in here; if it is not in here, ask me."*
5. **Pod formation, 10–15 minutes.** Do not skip or shorten this. Instructions are in Task 1: write down skills and expectations, then find two other unpaired people whose skills **complement** rather than duplicate yours. Default to threes. Make each pod exchange contacts and say one sentence about what they want to build, out loud.

## Running the studio

Work through Tasks 1–6 with the room, not ahead of it:

- **Task 1 (portfolio).** The trap is cloning the template instead of **Use this template → Create a new repository**. Watch for it. Then `gh auth login` and `gh repo clone` — *not* SSH keys; that path costs 20 minutes per student and teaches nothing relevant.
- **Task 2 (Git/Markdown).** Keep it to edits, commits, and one cross-link between two pods' notes. Consequences of a missed commit are more instructive than a lecture on branching.
- **Task 3 (`uv`).** One command installs a pinned Python and the tools. If someone's install fails on Python 3.14, that is a real dependency problem — note it and move on; the smoke test in `scratch/` is how you find those before class.
- **Task 4 (`sqlite3`).** Keep it interactive and line-by-line; the paste problem is explained in the module and in the [resource bank](../modules/Z-resources-bank.md#pasting-a-block-into-the-sqlite3-prompt).
- **Task 5 (SQL Island, 30 minutes).** Non-negotiable. Turn the lights down, tell them to switch the game to English, and let them play. Ask the four tutorial questions afterwards — five minutes, out loud, no notes.
- **Task 6 (telemetry).** Good "it works" moment: a real file, a real database, a real query.

## Where it goes wrong

- **SSH keys.** Do not teach them here. `gh auth login` with a browser is the whole lesson.
- **Windows without `sqlite3`.** Send them to the editor's **Git Bash** profile — see [where to run the labs](../modules/Z-resources-bank.md#where-to-run-the-labs-your-editors-terminal). The Python paths in the module work everywhere.
- **Students who finish early.** Point them at stretchers 8–11 (Datasette, shell power moves, Datasette Lite). Do not invent work.
- **A pod that formed badly.** Fix it in week 2, not week 8. It is much cheaper now.
